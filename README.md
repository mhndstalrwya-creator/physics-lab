# ElectroLab – مختبر الفيزياء والكهرباء التفاعلي

**ElectroLab** هو مختبر تعليمي تفاعلي باللغة العربية والإنجليزية يساعد الطلاب على مراجعة أساسيات الكهرباء والإلكترونيات من خلال القوانين، التجارب المبسطة، الاختبارات، والمختبر الافتراضي.

> هذا المشروع نسخة تعليمية تعمل بالكامل داخل المتصفح، ولا تحتاج إلى خادم خلفي أو قاعدة بيانات.

## المميزات

- واجهة ثنائية اللغة: العربية والإنجليزية.
- صفحة رئيسية للوصول السريع إلى أدوات المختبر.
- مختبر افتراضي مبسط للتجربة والتعلم.
- مكتبة قوانين تحتوي على 29 قانونًا ومعادلة في الكهرباء والإلكترونيات.
- حاسبة تفاعلية للقيمة المفقودة في القانون عند إدخال القيم المعروفة.
- صفحة للتجارب الإلكترونية والأنشطة التعليمية.
- اختبارات وتحديات: يتم اختيار 5 أسئلة عشوائية في كل جولة من بنك يضم 39 سؤالًا.
- صفحة ملف شخصي لحفظ التقدم محليًا.
- محلل صور تجريبي للتوضيح التعليمي.
- تصميم متجاوب مناسب للحاسوب والهاتف.

## التشغيل السريع

### الطريقة الأولى: فتح الملف مباشرة

1. نزّل المستودع أو اضغط **Code → Download ZIP**.
2. فك الضغط عن الملفات.
3. افتح `login.html` في Chrome أو Edge أو Firefox.
4. سجّل الدخول بحساب تجريبي أو أنشئ حسابًا من صفحة التسجيل.

### الطريقة الثانية: باستخدام خادم محلي

تشغيل خادم محلي أفضل لتجنب بعض قيود المتصفح على الملفات المحلية:

```bash
python3 -m http.server 8000
```

بعد ذلك افتح `http://localhost:8000` في المتصفح. يمكن أيضًا استخدام إضافة **Live Server** في Visual Studio Code.

## التقنيات المستخدمة

- HTML5 لبناء الصفحات.
- CSS3 للتصميم والتجاوب.
- JavaScript بنمط Vanilla JavaScript دون إطار عمل خارجي.
- `localStorage` لحفظ الحسابات التجريبية والتقدم داخل المتصفح.

## ملاحظات وحدود النسخة الحالية

- الحسابات والتقدم محفوظة محليًا في المتصفح، وليست نظام مصادقة آمنًا.
- لا توجد قاعدة بيانات أو خادم خلفي في هذه النسخة.
- محلل الصور تجريبي ويعتمد على منطق توضيحي، ولا ينفذ تعرفًا بصريًا حقيقيًا بالذكاء الاصطناعي.
- المختبر الافتراضي نموذج تعليمي مبسط وليس محرك محاكاة كهربائية احترافيًا.
- حذف بيانات المتصفح أو استخدام متصفح آخر قد يؤدي إلى فقدان الحساب التجريبي والتقدم المحفوظ.

## أفكار للتطوير مستقبلًا

- إضافة خادم خلفي وقاعدة بيانات للحسابات والتقدم.
- تطوير محاكاة كهربائية أكثر دقة للمقاومات والدوائر.
- ربط محلل الصور بنموذج رؤية حاسوبي حقيقي.
- إضافة رسوم بيانية وقياسات تفاعلية للتجارب.
- إضافة لوحة للمعلم لمتابعة نتائج الطلاب.
- توفير اختبارات قابلة للطباعة وتقارير للنتائج.
