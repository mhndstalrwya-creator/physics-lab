# ElectroLab – المختبر الإلكتروني الذكي

## تشغيل المشروع
1. فك ضغط مجلد `ElectroLab`.
2. افتح `login.html` في المتصفح لبدء الاستخدام.
3. سجّل الدخول باسمك، أو أنشئ حساباً من صفحة إنشاء الحساب.

يمكن تشغيل المشروع مباشرة عبر Chrome أو Edge أو Firefox، أو باستخدام إضافة Live Server في VS Code. لا يحتاج إلى خادم خلفي في هذه النسخة التجريبية.

## صفحات المشروع المستقلة
- `login.html` – تسجيل الدخول
- `register.html` – إنشاء حساب
- `home.html` – الرئيسية
- `lab.html` – المختبر الافتراضي
- `analyzer.html` – محلل الصور الذكي
- `experiments.html` – التجارب الإلكترونية
- `laws.html` – مكتبة تضم 29 قانوناً إلكترونياً مع بحث وحاسبة تفاعلية للقيمة المفقودة
- `quiz.html` – الاختبارات والتحديات؛ 5 أسئلة عشوائية في كل جولة من بنك يضم 39 سؤالاً، مع جولة جديدة مختلفة
- `profile.html` – الملف الشخصي

## الملفات المشتركة
- `style.css` – التصميم والألوان وتنسيق جميع الصفحات.
- `app.js` – وظائف الصفحات، الترجمة، تسجيل الدخول، وحفظ التقدم محلياً.

كل صفحة HTML مستقلة ويمكن تعديل محتواها دون الحاجة إلى تعديل صفحات HTML الأخرى. أما التنسيق المشترك والوظائف العامة فتوجد في `style.css` و`app.js`.

## ملاحظات النسخة التجريبية
- الحسابات والتقدم محفوظة محلياً في المتصفح باستخدام `localStorage` وليست نظام مصادقة آمناً أو قاعدة بيانات.
- محلل الصور تجريبي ويعتمد على اسم الملف، ولا ينفذ تعرّفاً بصرياً حقيقياً بالذكاء الاصطناعي.
- المختبر الافتراضي نموذج تعليمي مبسط وليس محرك محاكاة كهربائية كاملاً.

## التحديث الجديد
- صفحة القوانين تعرض 29 قانوناً ومعادلة في أساسيات الكهرباء والقدرة والطاقة والمكثفات والمقاومات وتحليل الدوائر والإشارات والمحولات. يمكن البحث واختيار أي قانون وإدخال القيم المعروفة وترك متغير واحد فارغاً لحسابه.
- صفحة الاختبارات تختار 5 أسئلة عشوائية في كل جولة من بنك أسئلة أكبر، وتحاول عدم تكرار مجموعة الجولة السابقة. عند إعادة الاختبار تحصل على مجموعة جديدة.
- جميع الإضافات تدعم العربية والإنجليزية وتعمل محلياً في المتصفح.
